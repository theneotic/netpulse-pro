Operational principles / 03

Not magic.
Just unbuffered measurement.

Engineered for network administrators, stream engineers, and gamers who need unbuffered connection telemetry with zero analytics telemetry.

01

Direct Edge Streams

Tests stream directly through nearest Cloudflare CDN edge nodes with nonces to prevent browser HTTP proxy caching.

02

RFC 3550 Jitter

Jitter is computed via successive RTT variance. Unveils subtle connection packet jitter even when raw bandwidth numbers look high.

03

Zero Data Retention

Your test data lives only inside your browser memory (`localStorage`). No tracking beacons, no analytics databases, zero data selling.
